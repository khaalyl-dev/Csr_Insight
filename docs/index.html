Project Structure

Monorepo layout for the CSR Insight platform. Deployment teams should configure each layer independently.

Csr_Insight/ ├── backend/ # Flask REST API │ ├── app.py # Entry point, blueprint registration │ ├── config.py # Environment configuration │ ├── init_db.py # DB init + seed data │ ├── requirements.txt │ ├── core/ # JWT, permissions, schema patches │ ├── models/ # 22 SQLAlchemy models │ ├── features/ # 17 Flask blueprints │ ├── rag_corpus/ # Chatbot knowledge base │ └── tests/ ├── frontend/ # Angular SPA │ ├── src/app.routes.ts # All route definitions │ ├── src/app.config.ts # Interceptors, i18n, session │ ├── src/core/ # Guards, interceptors, services │ ├── src/features/ # Domain screens + API clients │ ├── src/shared/ # Layout, sidebar, widgets │ ├── src/media/ # Uploaded files (MEDIA_FOLDER) │ └── proxy.conf.json # Dev proxy → localhost:5001 ├── Database/ # DBML schema, column reference ├── screenshot/ # UI screenshots └── docs/ # This documentation

API Endpoints Used

GET /api/csr-plans JWT

Purpose: List plans filtered by site, year, status.

Query: ?site_id=&year=&status=

POST /api/csr-plans

Purpose: Create new DRAFT plan.

{ "site_id": "uuid", "year": 2026, "validation_mode": "111", "total_hc": 500 }
PATCH /api/csr-plans/{id}/submit

Purpose: Submit plan for corporate validation workflow.

POST /api/csr-plans/import-excel-preview

Purpose: Preview Excel import before committing activities to DB.

Request: multipart/form-data — file, site_id, year

API Endpoints Used

GET /api/csr-activities

Purpose: List activities (work queue or all). Query: ?plan_id=&year=&exclude_realized=1

POST /api/csr-activities

Purpose: Create planned activity within a CSR plan.

{
  "plan_id": "uuid", "title": "Tree Planting", "category_id": "uuid",
  "activity_number": "ENV-001", "planned_budget": 15000,
  "planned_objectives": ["Plant 500 trees"], "draft": false
}
POST /api/csr-activities/off-plan-realization

Purpose: Create activity outside the original plan (requires approval).

GET /api/csr-activities/{id}

Purpose: Activity detail with objectives, attachments, status.
