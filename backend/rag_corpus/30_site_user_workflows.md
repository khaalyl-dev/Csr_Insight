# Site user workflows

Site users work on CSR plans and activities for **their assigned sites** only. They create or edit planned activities, attach documents, mark progress, and submit items for corporate validation when required.

If a user cannot find a plan or activity, common causes are: wrong year filter in the list, the item belongs to another site, or the plan is not yet visible under their assignments. Prefer USER_DATA for definitive counts and site lists.
