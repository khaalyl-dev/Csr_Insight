# CSR Insight — platform overview

CSR Insight is a web application for managing corporate social responsibility (CSR) plans and activities across industrial sites. Users navigate modules from the sidebar: dashboard, CSR plans, planned activities, realized activities, documents, change requests, tasks, and user management (corporate only).

The assistant combines **retrieved documentation** with a **live USER_DATA snapshot** from the database. Counts, statuses, and site-specific visibility always follow USER_DATA when there is any mismatch with static text.
